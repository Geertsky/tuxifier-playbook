# Glossary

### Kickstart

Kickstart, is a method of automatic installation introduced by Redhat.

### Minimal OS

An operating system with the least amount of software installed. The system can boot, and a user can log in to the system. Anything more, is considered out of the scope of minimal.
An ssh server, is normally considered as part of the minimum OS, where strictly speaking it falls out of the scope of a minimal OS.

### Partition layout

The partition layout is the division of, one or multiple, disk(s) into multiple usable chunks of storage for the operating system.

### Ansible

An infrastructure as code automation framework developed by Redhat.

### Terraform

An infrastructure as code automation framework developed by HashiCorp.

### Runtime-environment

The environment needed for software to run. This broadly includes the OS, but is often meant more specifically scoped.
Ansible uses Python, thus an Ansible runtime environment requires Python.

### Boot environment

A boot environment is the runtime environment at boot time.
It contains the minimal software needed to initialize the hardware where the Operating System is stored.

### root filesystem

The filesystem containing the operating system.
